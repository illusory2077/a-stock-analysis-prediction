# 预测方法说明

## 默认四维框架

| 维度 | 默认权重 | 主要输入 |
|---|---:|---|
| 大盘环境 | 30% | 上证指数、沪深 300、创业板指、成交额、市场宽度 |
| 资金行为 | 30% | 主力资金、融资融券、龙虎榜、成交量变化 |
| 技术面 | 25% | 均线、MACD、RSI、布林带、支撑阻力、波动率 |
| 消息面 | 15% | 公告、财报、行业政策、新闻、监管披露 |

## 预测输出

每份预测至少包含：

- 看多、看空或震荡；
- 概率估计；
- 预期价格区间；
- 支撑位和压力位；
- 触发条件；
- 失效条件；
- 风险提示；
- 数据截止时间和来源。

## 预测输入质量门禁

行情必须先经过 `src.analysis.quality_gate.evaluate_prediction_input`：

- `approved`：主源质量检查和主备交叉验证正常；
- `degraded`：主源可用，但存在备用源不可用、交叉验证跳过或普通质量警告；
- `blocked`：数据为空、质量错误、交易日历异常或主备行情不一致，不得计算预测。

门禁同时记录行情数据截止日、质量报告状态、交易日历状态和交叉验证状态。预测入口应使用 `require_prediction_input`，避免绕过门禁。

## 技术指标计算层

通过 `src.analysis.calculate_technical_indicators` 计算技术面特征。该入口会先执行预测输入质量门禁，只有 `approved` 或 `degraded` 数据可以计算，`blocked` 数据会抛出异常。

当前输出包括：

- `ma_5`、`ma_10`、`ma_20`、`ma_60`：简单移动平均线；
- `macd_dif`、`macd_dea`、`macd_hist`：12/26/9 MACD；
- `rsi_6`、`rsi_14`：相对强弱指标；
- `bollinger_mid_20`、`bollinger_upper_20`、`bollinger_lower_20`、`bollinger_bandwidth_20`、`bollinger_percent_b_20`：布林带；
- `true_range`、`atr_14`：真实波幅和平均真实波幅；
- `support_20`、`resistance_20`、`support_60`、`resistance_60`：滚动支撑/压力位；
- `return_1d`、`volatility_20`：收益率和波动率。

计算前会按交易日期升序排列，滚动窗口和指数平均只使用当前行及之前的数据，避免未来函数。历史记录不足时保留 `NaN`，并在摘要中记录告警，不用 0 填充。每日流水线默认使用目标交易日前 120 个自然日的历史行情，先通过质量门禁，再保存带指标数据到 `data/processed/market/indicators/`，并在 Markdown 报告中展示最新指标和指标告警。

## 防止未来函数

财报、公告、新闻和资金数据必须按公开披露时间进入模型。回测或历史复盘时，不能使用预测时点之后才公开的数据。

## 技术信号层

指标计算完成后，通过 `src.analysis.generate_technical_signals` 生成可审阅的技术判断。信号层不替代预测模型，也不构成买卖承诺，主要用于把指标事实转换为结构化解释：

- **趋势**：`MA5 > MA20 > MA60` 记为上升排列，反向排列记为空头排列；不完整历史只标记为数据不足。
- **MACD**：识别 DIF/DEA 金叉、死叉及当前柱体方向；金叉/死叉权重高于普通正负动量。
- **RSI**：默认 `RSI14 <= 30` 为超卖、`>= 70` 为超买；超买/超卖同时作为风险提示，不能单独视为反转确认。
- **布林带**：记录价格在中轨、上轨或下轨的位置，突破上轨/下轨分别标记为偏强/偏弱并提示过热或破位风险。
- **支撑/压力**：输出现价到 20 日支撑和压力的距离，不直接强行改变方向分数。
- **波动率**：按 20 日收益率标准差分为低（`<2%`）、中（`2%~4%`）和高（`>=4%`），高波动会降低信号可解释性。

综合分数由趋势、MACD、RSI 和布林带四个方向性组件构成：趋势 `-2~+2`、MACD `-2~+2`、RSI `-1~+1`、布林带 `-1~+1`。分数 `>=2` 输出 `bullish`，`<=-2` 输出 `bearish`，否则输出 `neutral`。信号强度为当前绝对分数占可用组件最大分数的比例；置信度还会考虑历史指标是否齐全以及质量门禁是否为 `degraded`。

信号层继续继承行情质量门禁：`blocked` 数据会抛出 `PredictionInputBlockedError`，不会生成信号；`degraded` 数据允许计算，但必须在摘要和日报中保留警告并降低置信度。逐日信号和元数据保存到 `data/processed/market/signals/`，不覆盖同一日期的既有结果。所有交叉、滚动和状态判断只使用当前行及历史行，避免未来函数。

## 次日预测实现

预测入口为 `src.analysis.generate_next_day_prediction`，输入是已经通过行情质量门禁、技术指标计算和技术信号生成的 `TechnicalSignalResult`。流水线顺序固定为：

```text
行情采集
  -> 统一标准化
  -> 预测输入质量门禁
  -> 技术指标
  -> 技术信号
  -> 次日预测
  -> JSON 存储
  -> 中文日报
```

### 四维权重与缺失数据

基础权重固定为：

| 维度 | 基础权重 | 当前接入状态 |
|---|---:|---|
| 大盘环境 | 30% | 已接入主要指数趋势/动量，市场宽度按可用性参与 |
| 资金行为 | 30% | 已接入主力净流入强度/连续性；融资融券余额变化和龙虎榜净买入作为可选补充证据 |
| 技术面 | 25% | 当前由技术信号层提供 |
| 消息面 | 15% | 已接入 Tavily 新闻时间截面和可解释关键词评分；公告/财报专用源待接入 |

未提供真实数据的维度会标记为 `available=false`，从有效权重分母中剔除后再归一化；**不会伪造评分，也不会把缺失维度当作中性事实**。因此目前仅技术面可用时，输出只能解释为技术面覆盖下的条件性估计，而不是完整四维模型结论。

预测结果包含：

- `bullish`、`neutral`、`bearish` 三类方向概率；
- 综合方向、置信度和数据覆盖率；
- 最新收盘价、预期变动百分比和价格区间；
- 每个维度的基础权重、有效权重、评分、证据和警告；
- 触发条件、失效条件、缺失维度和质量警告；
- 数据截止时间、目标交易日、生成时间和质量门禁结果。

置信度会受到数据覆盖率、信号强度和 `degraded` 门禁状态影响；覆盖率低于 50% 时置信度上限为 0.40。价格区间使用 `latest_close ± max(1.5×ATR14, 1.65×20日波动率, 1%)`，并限制最大半宽为 15%。这些概率和区间是模型估计，不是收益承诺或确定性买卖结论。

### 存储与报告

每日流水线通过 `src.storage.save_next_day_prediction` 保存 JSON 到：

```text
data/processed/market/predictions/{symbol}_{trade_date}_next_day_prediction.json
```

同一标的和交易日期再次运行时自动生成带 UTC 时间戳的旁路文件，不覆盖已有结果。日报中的 `#### 次日预测` 小节展示方向概率、价格区间、置信度、覆盖率、维度状态、缺失数据警告、触发条件、失效条件和结果文件路径。

### 质量与时间约束

- `blocked` 行情不得进入指标、信号或预测；
- `degraded` 行情可以继续，但必须在结果和报告中保留告警并降低置信度；
- 预测只能使用数据截止时间之前已经公开的数据，不能使用未来公告、新闻或修订数据；
- 指数或资金接口不可用时，必须明确缺失和限制，不能用模拟数据补齐；
- 真实成交和交易计划应优先使用未复权价格，技术指标必须记录复权口径；
- 时间戳统一保存为 UTC，同时保留交易所本地交易日。

## 大盘环境评分实现

大盘环境入口为 `src.analysis.evaluate_market_environment`。每日流水线通过 `DataSourceRouter.fetch_index_bars` 获取以下指数的历史日线，并在进入评分前完成统一标准化、质量检查、交易日历校验和主备交叉验证：

| 指数 | 标准代码 | 作用 |
|---|---|---|
| 上证指数 | `000001.SH` | A 股大盘趋势 |
| 沪深 300 | `000300.SH` | 大盘蓝筹和核心资产环境 |
| 创业板指 | `399006.SZ` | 成长风格和风险偏好环境 |

每个指数的方向评分由两部分组成：

- **趋势评分**：收盘价相对 20 日均线高出至少 0.5% 为偏强，低于至少 0.5% 为偏弱，否则为中性；
- **5 日动量评分**：5 日涨跌幅达到 `+2%` 或 `-2%` 时分别记为偏强或偏弱，区间内为中性。

指数评分先等权平均；如果传入真实市场宽度（上涨家数和下跌家数），市场宽度占组合 25%，指数评分占 75%。缺少指数或市场宽度时不填充为中性事实，并在 `warnings` 中记录缺失。不同指数最新日期不一致时，评分统一截断到最早共同截止日，避免混用不同时间截面。

`MarketEnvironmentResult.to_dimension()` 会转换为次日预测层的 `market_environment` 输入，包含 `available`、`score`、`evidence`、`warnings`、`data_cutoff` 和 `source`。当前大盘环境接入后，预测会根据实际可用维度重新归一化权重；指数接口全部失败时，预测仍可在技术面覆盖下运行，但必须显示缺失告警和较低覆盖率。


## 资金行为评分实现

资金行为入口为 `src.analysis.evaluate_fund_flow`。每日流水线通过 `DataSourceRouter.fetch_fund_flow` 获取个股资金流向，优先使用 Tushare Pro `moneyflow`，AKShare 个股资金流接口作为备用研究源。标准化字段包括 `net_flow_amount`、`net_flow_pct` 以及超大单、大单、中单、小单净流入金额，金额统一为人民币元，并保留 `source`、`retrieved_at`、`data_version` 和原始响应。

### 融资融券与龙虎榜补充

每日流水线还会独立调用 `DataSourceRouter.fetch_margin` 和 `fetch_dragon_tiger`。融资融券统一为融资余额、融资买入/偿还、融券余额、融券余量、融券卖出/偿还量和融资融券余额字段；龙虎榜统一为上榜原因、收盘价、涨跌幅、换手率、净买入额、买卖额和机构/营业部净额字段。金额按供应商原始口径统一为人民币元（Tushare `margin_detail`/`top_list` 金额字段本身为元，不重复换算）；融券卖出/偿还保留为股数。所有记录保留来源、获取时间、版本和原始响应。两者只作为资金行为维度的补充证据：融资余额变化偏多、融券余额变化偏空，龙虎榜净买入和机构净买入偏多；数据不足时子项保持不可用，不用 0 填充。

评分规则如下：

- **强度**：最新主力净流入除以最近 20 个交易日净流入绝对值中位数，再使用 `tanh` 限制在 -1 到 +1；
- **连续性**：最近 5 个交易日净流入方向均值；
- **综合评分**：强度占 65%，连续性占 35%；
- 历史不足、基线为零或主备差异超阈值时保留告警，不伪造缺失值。

`FundFlowResult.to_dimension()` 会把评分转换为次日预测层的 `fund_flow` 输入。资金数据不可用时，该维度从有效权重分母中剔除，预测结果仍会显示资金维度缺失和覆盖率限制。原始数据保存到 `data/raw/fund_flow/`，标准化结果、质量报告和主备审计保存到 `data/processed/fund_flow/`。


## 消息面评分实现

消息面入口为 `src.analysis.evaluate_news`。每日流水线在个股预测之前调用 `DataSourceRouter.search_news`，将结果标准化、去重并执行信息截面筛选，然后把评分传入 `generate_next_day_prediction(news=...)`。

消息面时间约束：

- 时间戳统一转换为 UTC，同时按 `Asia/Shanghai` 解释无时区时间；
- 目标交易日的 `date` 截面按当天本地时间 23:59:59.999999 处理；
- 缺少或无法解析 `published_at` 的新闻不参与评分，但会保留排除原因；
- 晚于信息截面的新闻不参与预测，并在报告中标记为 `excluded_after_cutoff`；
- 评分仅使用截面之前的新闻，避免把搜索结果获取时间误当成公开时间。

当前评分是透明基线：对标题、摘要和正文中的预设利好/利空关键词计数，使用 `tanh` 将单条情绪限制在 -1 到 +1，再按 Tavily 相关性分数作轻量加权。它不是 NLP 事实核验，也不替代交易所公告、公司披露或专业新闻终端；未识别关键词时会保留中性评分告警。
